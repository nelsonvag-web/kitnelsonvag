
# Prompt: Criar Mensagens Comerciais

## Objetivo
Criar mensagens comerciais para prospectar novos clientes e recuperar clientes antigos do mercado imobiliário.

## Modelo

CONTEXTO
Sou consultor comercial do Sistema Coruja, uma plataforma de produtividade para imobiliárias e corretores.

INSTRUÇÃO
Crie uma mensagem comercial para [tipo de cliente ou situação].

OBJETIVO
Quero despertar o interesse do cliente em conhecer ou voltar a utilizar o Sistema Coruja.

FORMATO
Mensagem curta para WhatsApp, com linguagem profissional, amigável, consultiva e persuasiva, sem pressão de venda.

DIFERENCIAIS
- Sistema de gestão imobiliária.
- Consulta de tabelas de imóveis.
- CRM para acompanhamento de clientes.
- Site imobiliário.
- Integração com portais imobiliários.
- Ferramentas de produtividade.

RESULTADO ESPERADO
Uma mensagem pronta para personalizar e enviar ao cliente.
