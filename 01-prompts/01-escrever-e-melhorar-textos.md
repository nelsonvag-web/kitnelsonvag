# Prompt: Escrever e Melhorar Textos

Use quando você tiver uma ideia, um rascunho ou uma mensagem e quiser transformar isso em uma comunicação mais clara.

## Modelo

Copie pelo botão no canto do bloco, troque o que está entre colchetes e cole na IA que você usa.

```text
CONTEXTO
Estou escrevendo para [público/situação].

INSTRUÇÃO
Ajude a [escrever / revisar / reorganizar / simplificar] o conteúdo abaixo.

OBJETIVO
Quero que a pessoa entenda [resultado desejado].

FORMATO
Entregue em [e-mail / mensagem / post / texto curto / tópicos], com tom [direto / profissional / informal / didático].

CONTEÚDO BASE
[cole aqui suas ideias, fatos ou rascunho]
```

## Antes de Usar

- Confira se a IA preservou sua intenção.
- Revise fatos, nomes, datas e números.
- Ajuste o texto para que continue parecendo seu.
## Exemplo prático – Sistema Coruja

CONTEXTO
Estou entrando em contato com imobiliárias que já utilizaram o Sistema Coruja, mas não renovaram seus planos.

INSTRUÇÃO
Crie uma mensagem comercial para WhatsApp.

OBJETIVO
Despertar o interesse do cliente em reativar o acesso às tabelas de imóveis e ferramentas de produtividade.

FORMATO
Mensagem curta, amigável, profissional e sem pressão de venda.

CONTEÚDO BASE
O cliente pode voltar a utilizar o sistema de consulta das tabelas de imóveis sem contratar o site. A renovação será somente em fevereiro de 2027.
