
# Kit de Inteligência Artificial – Marketing Imobiliário

## Sobre o projeto

Este projeto reúne prompts, modelos, checklists, habilidades e processos de automação utilizando Inteligência Artificial.

O objetivo é aplicar a IA na rotina comercial, no marketing e na produtividade de imobiliárias, corretores e empresas do mercado imobiliário.

## Autor

Vagner Penteado

Consultor comercial e entusiasta de Inteligência Artificial.

## Estrutura do projeto

### 01-prompts
Prompts para comunicação, vendas, campanhas e tomada de decisões.

### 02-templates
Modelos prontos para prospecção, follow-up e reativação de clientes.

### 03-checklists
Listas de verificação para revisar conteúdos e organizar tarefas com IA.

### 04-skills
Instruções especializadas para executar tarefas, incluindo preparação de reuniões.

### 05-delegacao-e-automacao
Processos, gatilhos de automação e supervisão de tarefas.

## Aplicações práticas

- Marketing imobiliário.
- Prospecção de clientes.
- Recuperação de imobiliárias inativas.
- Comunicação comercial.
- Planejamento de campanhas.
- Organização de vendas.
- Produtividade com Inteligência Artificial.

## Ferramentas utilizadas

- ChatGPT
- GitHub
- Inteligência Artificial generativa

## Objetivo de aprendizado

Desenvolver habilidades práticas em Inteligência Artificial e criar soluções que possam ser aplicadas no mercado imobiliário.
